# Excel Watermark POI (Legacy Version)

Legacy implementation of an Excel watermark utility built with Apache POI.

This repository contains the original version of the project before the Java 17 refactor and modernization process.

## Background

The project was originally created to solve a practical issue while working with Apache POI:
most available examples only supported either:

- printable watermarks
- or visible sheet watermarks

but not both together in a simple implementation.

This repository preserves the initial solution and approach used during that stage of development.

## Technologies

- Java
- Apache POI
- Maven

## Purpose

This legacy version is kept for:

- historical reference
- compatibility testing
- comparison against newer implementations
- experimentation with Apache POI watermark behavior

## Notes

A modernized Java 17 version of this project is available in the updated repository.

## Features

- Excel watermark generation
- Apache POI integration
- Spreadsheet watermark rendering
- Printable watermark support
